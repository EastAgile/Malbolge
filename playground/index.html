Run Malbolge in your browser on the WebAssembly build of fastbolge. It uses the same engine as the native interpreter and passes the same conformance suite, checked against Ben Olmstead's 1998 reference interpreter.

Newlines are sent as typed.

Classic is Malbolge as the reference interpreter runs it: 10-trit words, 59,049 cells, whitespace skipped on load, and output truncated to a byte. Where the reference would hang or read out of bounds, fastbolge stops and says why.

    
fast20 is the 19-trit Malbolge Unshackled dialect that MalbolgeLisp ships with. Memory is 319 cells, created a chunk at a time as the program touches it.

    
Output is shown as text. Bytes outside printable ASCII appear dimmed as \xNN, so a program printing the end-of-file value (59048 mod 256) shows \xa8.
